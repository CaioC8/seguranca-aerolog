# Documentos finalizados

Esta pasta é reservada às versões revisadas, aprovadas pelo grupo e prontas para entrega.

## Controle de versão

- Mantenha nomes estáveis: `01_PSI_AeroLog.docx`, `02_PGR_AeroLog.docx` e `03_PCN_AeroLog.docx`.
- Registre no commit qual documento foi aprovado e quais revisões foram feitas.
- Crie uma tag para cada entrega, por exemplo `entrega-v1.0`, `entrega-v1.1` e `entrega-v2.0`.
- Se também houver PDFs finais, use os mesmos nomes-base dos arquivos DOCX.

Assim, qualquer versão entregue pode ser recuperada pelo histórico ou pela tag, sem acumular cópias numeradas no repositório.
