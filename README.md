# Segurança da Informação — AeroLog

Repositório da atividade acadêmica sobre a empresa fictícia AeroLog Transportes Aéreos. O trabalho contempla uma Política de Segurança da Informação (PSI), um Plano de Gestão de Riscos (PGR) e um Plano de Continuidade de Negócios (PCN).

## Estrutura

```text
.
├── modelos/                  # Arquivos-base fornecidos para produzir os documentos
├── documentos/
│   ├── em-elaboracao/        # Versões que ainda estão sendo trabalhadas
│   └── finalizados/          # Versões aprovadas/prontas para entrega
└── referencias/              # Estudo de caso e guia de elaboração
```

## Fluxo de trabalho

1. Copie o modelo necessário de `modelos/` para `documentos/em-elaboracao/`.
2. Edite somente a cópia. Os modelos devem permanecer inalterados.
3. Registre as alterações no Git durante a elaboração.
4. Depois da revisão e aprovação do grupo, mova o arquivo para `documentos/finalizados/`.
5. Identifique cada entrega final com uma tag do Git, por exemplo `entrega-v1.0`.

As regras específicas de nomenclatura e versionamento estão descritas nos arquivos `README.md` de cada pasta de documentos.
